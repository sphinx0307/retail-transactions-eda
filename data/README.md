# Dataset

The notebook expects `Retail_Transactions_Dataset.csv`, but the dataset was not provided with the notebook upload and is therefore not included here.

Before running the notebook:
1. Obtain the dataset from its original authorized source.
2. Check its license and whether redistribution is permitted.
3. Update the CSV path in the notebook to point to your local copy.

Do not commit private, sensitive, or non-redistributable data.
